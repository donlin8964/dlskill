# DLSkill 框架库 v0.5

四个框架的完整结构、详解和使用边界。根据 SKILL.md 第3步选定的框架读对应章节。

## 框架一：PREP 观点框架

**适用场景**：人设类、观点类、共鸣类短视频口播、朋友圈长文、公众号文章。

### 结构公式

```
【P - 观点】第一句直接砸，带情绪，不绕弯
【R - 道理】把观点讲透，用扎心的比喻
【E - 例子】用你自己的真实故事，别编
【P - 升华】往上顶，落到身份认同，找同类
```

### P - 开头观点（0-5秒）

开头三要素：**话题 + Hook + 可信度**。

开头铁则：
1. **开头必须独立工作**：不能假设用户看了标题和封面，第一句话就要把事说清楚
2. **留悬念，别给答案**：
   - ❌ "李亚鹏30年干黄十几个项目，证明人脉不等于钱"（直接给结论）
   - ✅ "善良的李亚鹏，认识半个娱乐圈，30年为什么赚不到钱？"（留问号）
3. **要口语化，别自问自答**：
   - ❌ "你以为你在自律？其实你在逃避。"（念着别扭）
   - ✅ "只要你没在执行，你做的那些事大概率都是为了逃避执行。"

开头素材优先级（从高到低）：
1. ⭐⭐⭐⭐⭐ **晒结果+反转**："去年我日更了100条视频，很多人问我怎么坚持的，其实我只是想通了一件事。"
2. ⭐⭐⭐⭐ 数据冲击："80%的创业者，死在了前6个月。"
3. ⭐⭐⭐⭐ 反常识："睡觉才是最好的养生，不是打坐。"
4. ⭐⭐⭐⭐ 金句断言："钱是燃料，不是目的地。"
5. ⭐⭐⭐ 你的糗事/转变："我30岁财务归零的时候才想明白这件事。"

**内容不行，再怎么磨开头也没用。** 开头是内容的试用装，内容本身没料，开头写得再花也留不住人。

### R - 中间道理

- 不要讲大道理，要讲区别、讲本质、讲"大部分人错在哪"
- 多用对比："商人是什么样...但我们这种人不是..."
- 比喻要扎心，不要正确："钱袋子"比"计算器"好，"给虚无造条路"比"创新"好
- 记得讲"为什么"：加一句"因为..."，那个"因为"才是让人恍然大悟的东西

### E - 你的故事

- 必须是你真经历过的，别编
- 别怕露怯："我30岁，财务归零，卡里就八千块"比"我当年创业多么不容易"强一百倍
- 讲你之前怎么傻、怎么错、怎么想通的

### P - 结尾升华

- 不要落在方法上，要落在身份上
- ✅ "那才是我们这种人，活着的意义。"
- ❌ "所以大家一定要勇敢做自己哦。"
- 最后一句要轻、要重、要像暗号，像认亲

## 框架二：AITDA 转化框架

**适用场景**：卖课、带货、知识付费、社群招募、养生/玄学/财商/身心灵类转化视频。

### 结构公式

```
【A - Attention】反常识+极端案例，0-3秒钉住人
【I - Interest】把反常识变成他也想知道答案的问题
【T - Trust】用他天天见的常识讲背后的道理，让他点头
【D - Desire】两头拉扯：得到的爽 × 得不到的痛
【A - Action】简单直接明确，告诉他下一步点哪
```

### A - Attention（0-3秒，抓注意）

核心：一句话违背常识，让人"啊？"一声。
- ✅ "我师父6年没吃饭了，滴米未进。"
- ✅ "你睡了几十年觉，可能连睡觉的门都没摸到。"
- ❌ "今天给大家讲一讲睡眠的重要性。"

公式：极端案例 / 反常识断言 / 颠覆认知的事实。

### I - Interest（3-30秒，勾兴趣）

核心：把那个奇怪的事，变成一个他也想知道答案的问题。
- "他能量从哪来？""为什么有人越养越虚？""为什么你睡了8小时还是累？"
- 不要急着给答案，先让他心里痒："对啊，为什么？"
- 本质：把"我的内容"变成"他的问题"

### T - Trust（30秒到2/3处，建信任）

**最关键一步，90%的人死在这。** 不是吹自己多厉害，是用他天天经历的事讲道，让他自己点头说"对"。
- 从日常切入："最累的时候你会干嘛？肯定是睡觉啊，谁累极了去打坐？"
- 用他已知的推导："小孩睡觉是不是手随便一扔就着了？身体硬的人肯定睡不好。"
- 用老话背书："黄帝内经讲'恬淡虚无，真气从之'。"
- 高级技巧：主动说"外行才XXX，高手都XXX"，把他拉到懂行的这边
- 标准：他边看边点头"对哦，我就是这样"，信任就成了

### D - Desire（最后1/3，放大欲望）

核心：两头拉到极致，让他心痒难耐。

正向放大（得到的爽）：
- "睡好了，健康就搞定一半。""就这一个功法，已经值回票价。"

反向放大（得不到的痛）：
- "不懂自己就去养生，结果只有四个字：适得其反。"

四个高级技巧：
1. **禁忌感**："有些话讲太透视频会被删，直播间详细说"——越不让听越想听
2. **稀缺感**："这功法我当年在桂林跟师父学了7天，就这一招"
3. **零风险**："三天听完觉得没收获，全额退"——把决策风险降到零
4. **价格锚**："原来最低299，现在公益价"——让他觉得占了便宜

### A - Action（最后5秒，行动指令）

- 简单、直接、明确，别让他想
- ✅ "点击左下角小黄车，现在就报名。"
- ❌ "感兴趣的朋友可以了解一下哦。"
- 加紧迫感："就这波福利，过了就恢复原价。"

## 框架三：五字爆款法（救赎叙事）

**适用场景**：个人成长、经验分享、IP日更、认知类内容。讲"我踩过坑→我想通了→你也可以"的故事。**目前验证过出爆款率最高的结构。**

### 底层逻辑

这不是技巧，是人的心理结构：人不信老师，人信同伴。你先把自己踩坑的样子亮出来，观众防心一卸，后面说什么都听得进去。这是"救赎叙事"——我和你一样痛，我找到了路，你也可以。

### 五字公式

```
【痛】你的问题是什么（0-5秒，筛选+共鸣）
【我】我以前比你还惨（5-30秒，建立信任，自己当反面教材）
【转】真正的答案是什么（30秒-2/3，认知翻转，啊哈时刻）
【法】我现在怎么做（2/3-结尾，社会证明，可复制）
【值】送你一句话/一个问题/一个动作（结尾，获得感+行动）
```

### 痛——你有什么病

- 第一句直接点病，不绕弯："99%的人想太多把自己想废了"
- 要让观众觉得"在说我"
- 可以先否定其他答案再给真答案："不是不努力，不是没天赋，是想太多"
- 公式：**人群+症状+唯一病因**

### 我——我以前病得更重

- 用你自己的真实经历当反面教材，越具体越扎心
- 数字越精确越可信："7年，8400篇笔记，一千多万字"
- 讲你当时怎么傻、怎么躲、怎么自欺
- 本质：你不是来教我的，你是和我一样的人

### 转——原来不是X是Y

- 全篇的"啊哈时刻"，决定转不转发
- 用对比制造翻转："不是没压力，是低威胁高挑战""不是逼出来的，是松出来的"
- 可以用一个词、一个概念、一句老话把窗户纸捅破
- 要让人"原来如此"

### 法——我现在这么做

- 证明翻转是真的：我现在的状态和以前不一样
- 具体到动作："手机一支，灯都不打，张嘴就来"
- 不用完美，要真实可复制
- 让观众觉得"他能做到，我也能"

### 值——你带走什么

- 一个灵魂拷问："你是在解决问题，还是在想它来逃避做它？"
- 或一个行动指令："少想点，做点"
- 或一句金句："脑子是帮生命创造的，不是困住生命的"
- 最后要轻、要准、要像钉子

### 与其他框架的关系

- vs PREP：PREP是"我有个观点你听听"，五字法是"我和你一样但我走出来了"，更适合建立信任和共鸣
- vs AITDA：AITDA是"我有东西你买不买"，五字法是"我把心掏给你看"，不直接卖但信任到了自然转化
- 与AITDA对应：痛=Attention，我=Trust，转=Interest+Desire，法+值=Action

已验证爆款案例：《想太多》《日更8天》《学会休息》。

## 框架四：P-STAR故事传播法

**适用场景**：人物故事、事件解读、借事说理、商业案例拆解、短视频口播。手上有一个震撼的真实故事/事件，想借它讲出时代洞察或人生道理时用。**不要用PREP——观点先行会杀掉故事的悬念和张力。**

### 底层逻辑

人天生爱听故事，不爱听课。但经典STAR有个传播死穴：S直接铺事实，前3秒没有情绪钩子，普通人一看"某某大佬""某公司"就觉得"这是别人的事，跟我没关系"，直接划走。所以必须在STAR前面加一个P（Punch），先扎"你"的痛点，再进"他"的故事。说服力不来自嗓门，来自故事本身的重量；但留不住人，再重的故事也白搭。

### 结构公式

```
【P - Punch】0-3秒，一句话钉住人（扎你的痛点/反常识断言/制造悬念）
【S - Situation】3-15秒，把场景钉死，让人"看见"那件事
【T - Target/矛盾】他想要什么？什么东西在拦着他？
【A - Action】他做了什么反常识的选择？（高潮）
【R - Result/Insight】结果+这跟你有什么关系（落回P扎的那个痛，首尾闭环）
```

### P - Punch（钩子，0-3秒，最关键）

**P-STAR和经典STAR最大的区别**：P讲的是"你"的事，S才开始讲"他"的事。让普通人第一秒觉得"这说的是我"或"我想知道为什么"。

四种写法（选一个最扎的）：
1. **扎心痛点**："你有没有这种感觉，忙了一天什么真正重要的事都没干成？"
2. **反常识断言**："钱能买到一切，但有一样东西你花多少钱都买不到。"
3. **制造悬念**："一个要什么有什么的人为什么还要走？答案可能让你后背发凉。"
4. **直接给结论留原因**："大公司正在杀死你最重要的能力，连谷歌最顶级的人都受不了。"

铁则：**P和R必须首尾呼应**——P扎的那个痛，R必须给那个痛一个出口或解释，形成闭环。P不要剧透答案，要制造一个"为什么"的缺口。

### S - Situation（场景，3-15秒）

- 不是平铺直叙交代背景，是用**细节和反差**把场景立起来
- 数字、名字、画面感："27年""第30号员工"
- **砍掉普通人听不懂的技术名词**（MapReduce、TensorFlow这类一律换成"谷歌AI底座就是他搭的"这种大白话）
- 结尾要有一个"这事儿不一般"的反转："结果他走了"
- 标准：听众脑子里开始出画面，心里冒出"然后呢"

### T - Target/矛盾（15秒-1/3处）

- 他想干的事是什么？不是表面目标，是那个**"为什么在原来的地方干不了"**的矛盾
- 矛盾是故事的引擎：有资源但没自由、有地位但没专注、有钱但没时间
- 让听众理解"他不是待不下去才走，是想干的事太大，原来的地方装不下"
- 关键句式："不是X，恰恰是Y"
- 要点题P埋下的那个痛，让听众觉得"他的矛盾就是我的矛盾"

### A - Action（1/3-2/3处，高潮）

- 具体做了什么选择，重点是那个**反常识的放弃**
- 放弃了什么？选择了什么？跟谁一起？
- 数字越具体越有冲击力："四个人加起来在谷歌待了超过一百年""放弃上亿年薪"
- 要有画面感、有重量，让人倒吸一口气

### R - Result/Insight（2/3-结尾，升华）

R是双关：
- **Result**：这个选择产生了什么影响/震荡（股价跌了、行业震动了）
- **Insight**：这件事折射出的时代真相是什么

最关键：**从故事落回P扎的那个痛**——P说"你注意力被切碎了"，R就说"所以你该怎么办"。不要停在"某某真牛"，要停在"你要问自己的是什么"。最后一句要轻、要准、要像钉子，和P形成闭环。

### 使用要点

1. **P和R必须首尾呼应**：P扎什么痛，R解什么痛
2. **S要短平快**：15秒内进入矛盾，技术名词全砍
3. **A是高潮**：把最有冲击力的选择和数字放这里
4. **T要桥接P和A**：让"他的矛盾"变成"你的矛盾"
5. **一段一个故事一个理**：别一个视频讲三个故事，那叫流水账
6. **写完先测P**：把S/T/A/R全遮住，只看P，你想不想往下听？不想就改P

### 与其他框架的区别

- vs PREP：PREP"我先告诉你观点再讲道理举例子"；P-STAR"我先扎你一下，再给你讲个事，你自己品"，说服力来自故事+情绪
- vs 五字法：五字法需要讲述者亲身经历；P-STAR可以讲别人的故事
- vs AITDA：AITDA终点是"买"，P-STAR终点是"懂了"
- vs 经典STAR：多了一个P，解决"前3秒留不住人"和"这跟我有什么关系"两个传播死穴
