# dlskill 东临内容创作方法论

> 不评判想法，只提炼真意。给每个创造者的想法，装上传播的翅膀。

dlskill 是一套自媒体内容创作 AI 技能：丢给它一个模糊想法或 raw 素材，它帮你挖出真正的「核」，匹配传播结构，翻译成有穿透力的语言。

**最新版本：v0.7.0**

---

## v0.7.0 更新

**工程化升级**：新增 VERSION 版本文件，README 采用标准化更新日志格式，新增 docs/ 和 scripts/ 目录。为 v1.0 多 skill 拆分做准备。

**核心能力升级**：
- 新增 STAR 经历结构（第五大框架），覆盖"情景→任务→行动→结果"叙事模式
- 新增「定标题」环节（第4步），标题就是真意核的一句话表达，写之前先定锚
- 新增故事写作工具箱：短故事用「故事五要素」（背景/目的/行动/阻碍/结果），长故事用「英雄八步」（背景/目的/行动/阻碍/结果/意外/转折/结局）
- PREP 强化：百亿营收验证的说服模型定位，反专家自嗨约束，观点必须有情绪张力
- AITDA 强化：新增完整案例拆解（师父六年没吃饭），三派群体覆盖原理（理性/感性/行动），两种 Action 结尾模式（下单式/互动式），D 部分极限拉扯方法论

**质检升级**：
- 新增标题复测（带入观众视角，想不想点？有没有跑题？）
- 新增情绪张力检查（观点是不是干巴巴的正确废话？）
- 新增案例完整性检查（有没有用泛化场景偷懒代替真实案例？纯认知=专家自嗨）
- 快速自检口诀从 7 条升级为 9 条

**平台适配升级**：
- 视频号新增核心定位：情绪+人设+产品三要素，本质是社交裂变不是算法推荐
- 新增制作工具建议（开拍一键剪辑），内容质量>口播>剪辑>画面的优先级原则
- 速查表新增「核心逻辑」列

**流程扩展**：从 8 步扩展为 9 步（选题评估→找真意核→匹配情绪扣→选框架/混搭→定标题→搭结构填内容→开头3秒测试→语言翻译→分层质检→平台适配）

## 五大传播框架

| 框架 | 适用场景 | 一句话特征 |
|------|---------|-----------|
| PREP | 观点、人设、共鸣 | "我有个观点你听听"（百亿营收验证的说服模型） |
| AITDA | 卖课、带货、转化 | "我有东西你买不买"（覆盖理性/感性/行动三派） |
| 五字爆款法 | 成长故事、IP 日更 | "我和你一样痛但我走出来了"（出爆款率最高） |
| P-STAR | 人物故事、借事说理 | "你先别划走，这个人这件事跟你有关" |
| STAR | 经历分享、案例复盘 | "我经历了一件事，给你讲讲" |

## 安装

### 一键安装（推荐）

在支持 Skills 的 AI 工具里直接发送：

```
npx -y skills add donlin8964/dlskill -g --all
```

> `-g` 全局安装，`--all` 装到所有 AI 工具并跳过确认。

### 手动安装

1. 下载本仓库
2. 把整个文件夹（含 `SKILL.md`）放到对应工具的技能目录：
   - 通用：`~/.agents/skills/dlskill/`
   - 豆包：`~/.super_doubao/super-doubao-runtime/workspace/.user_skills/dlskill/`
3. 重启对话

## 使用方法

直接把想法丢给 AI：
- "我有个想法：创业和打工不一样，帮我写条口播"
- "这段文案帮我磨一下开头：[粘贴文案]"
- "用五字法写一条关于焦虑的日更稿"
- "帮我诊断这段逐字稿的问题"
- "给这个选题出3个标题"

AI 会按 **9 步**处理：选题评估 → 找真意核 → 匹配情绪扣 → 选框架/混搭 → 定标题 → 搭结构填内容 → 开头3秒测试 → 语言翻译 → 分层质检 → 平台适配。
