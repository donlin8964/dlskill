## dlskill 怎样工作

**单步路由：每次只推进一个当前任务。** 先完成本轮，再依据真实反馈决定下一步。

```
真实任务（选题/草稿/修改需求）
        │
        ▼
   /dls 读取上下文并选择
        │
        ▼
  1 个当前 Skill 完成任务
        │
        ▼
     本轮结论
   ┌────┼────┐
   ▼    ▼    ▼
 回到  尊重  留在
 /dls  用户  当前
       选择  Skill
```

**原则：一次只选择 1 个当前 Skill；每轮结论成为下一次路由的输入。**

## dlskill 解决什么问题

你不需要先学一套复杂的方法，也不需要知道该调用哪个工具。把当下的选题、草稿、卡点交给 `/dls`，它会根据对话上下文选择当前适合的 Skill。

| 真实处境 | 你会得到 |
|---------|---------|
| 有个想法但不确定值不值得做 | 选题三关评估 + 改造方向 |
| 有选题但写不出来，或者写出来很干 | 9步流水线从零写稿，真意核五层追问 |
| 稿子写完了但感觉不对，说不出哪不对 | 全维度诊断：真意核审查 + 共鸣诊断 + 逻辑延续检查 |
| 开头3秒留不住人，划走率高 | 开头专项优化，素材提取/增补/悬念三法 |
| 内容有料但语言太书面、有黑话 | 语言磨稿，反黑话 + 加金句 + 调节奏，标记式改稿 |
| 发布前想最后过一遍，怕踩坑 | 三层质检：选题层 / 段落层 / 全文层 |
| 同一篇内容要发抖音/小红书/公众号 | 五大平台适配，一稿多发方法 |
| 看到爆款想知道为什么火，怎么抄 | 9维度爆款拆解模板 + 仿写建议 |
| 标题总是起不好，点进来的人少 | 六种标题类型 + 平台适配 + Top3推荐 |

## 快速开始

安装完成后，直接在 Agent 中输入：

```
/dls 我想做一个关于"长期主义"的口播稿，目标人群是创业者，3分钟左右
```

`/dls` 会读取当前对话信息，选择合适的分析路径。完成一轮后，继续补充新的事实或反馈，再输入 `/dls`，它会判断当前该推进什么。

已经知道需求时，可以直接调用具体 Skill：

```
/dls-topic 我想讲"普通人如何坚持写作"，这个选题行不行？
/dls-write 帮我写一篇关于"睡眠才是最好的养生"的口播稿，发视频号
/dls-diagnose 这是我刚写的稿子，帮我诊断一下问题在哪：[粘贴文稿]
/dls-hook 这是我短视频前20秒的逐字稿，帮我优化开头：[粘贴文稿]
/dls-polish 稿子内容没问题，但语言太书面了，帮我改成口语化：[粘贴文稿]
/dls-check 发布前帮我过一遍质检：[粘贴文稿]
/dls-platform 这篇稿子要同时发抖音和小红书，帮我适配：[粘贴文稿]
/dls-title 帮我给这篇稿子起3个标题：[粘贴文稿]
/dls-iteration 帮我拆解这条爆款视频为什么火：[粘贴链接或文稿]
```

| 工作目标 | 主要入口 | 常见产出 |
|---------|---------|---------|
| 评估选题值不值得做 | `/dls-topic` | 三关评估结果 + 改造方向 + 多选题横向对比 |
| 从零写出完整口播稿 | `/dls-write` | 真意核 + 框架选型 + 完整逐字稿 + 开头3秒测试 |
| 诊断稿子的问题在哪 | `/dls-diagnose` | 真意核审查 + 五维度共鸣诊断 + 逻辑延续检查 + 标记式改稿 |
| 优化开头3秒留人 | `/dls-hook` | 内容质量前置检查 + 三种方法生成方案 + Top3推荐 |
| 打磨语言、去黑话、加金句 | `/dls-polish` | 标记式改稿 + 改动清单 + 口语化最终版 |
| 发布前三层质检 | `/dls-check` | 选题层 + 段落层 + 全文层12项检查 + 快速自检口诀 |
| 起标题 | `/dls-title` | 六种类型 + 平台适配 + Top3推荐 + 禁忌清单 |
| 多平台内容适配 | `/dls-platform` | 抖音/视频号/小红书/公众号/朋友圈适配 + 一稿多发方案 |
| 拆解爆款、积累迭代 | `/dls-iteration` | 9维度拆解模板 + 可复制方法提炼 + 仿写建议 |

> 不确定用哪个？输入 `/dls`，主入口会根据你的当前状态判断。

## 核心方法论

### 真意核

每篇内容只能有一个核心。挖到第5层，找到那个「对就是这个」的点。核不对，写得再多也是空的。

**五层追问法**：这篇在讲什么？→ 真正在讲什么？→ 戳中了谁的什么痛？→ 为什么这个痛重要？→ 一句话总结真意核。

### 五大框架

| 框架 | 结构 | 适用场景 |
|------|------|---------|
| **PREP** | 观点→道理→例子→升华 | 人设类、观点类、共鸣类 |
| **AITDA** | 注意→兴趣→信任→欲望→行动 | 卖课、带货、转化类 |
| **五字爆款法** | 痛→我→转→法→值 | 个人成长、经验分享，出爆款率最高 |
| **P-STAR** | 钩子→场景→矛盾→行动→结果 | 借事说理、人物故事 |
| **STAR** | 场景→目标→行动→结果 | 纯经历叙事 |

混搭原则：前半段建立信任/共鸣，后半段负责转化/升华。最多两个框架混，三个就乱了。

### 三层质检

1. **选题层**：痛不痛 / 反不反 / 真不真 — 三个不过直接换选题
2. **段落层**：情绪扣 / 金句 / 立场 — 写一段查一段
3. **全文层**：只有一个核 / 摘出3句金句 / 认亲测试 / 大白话 / 负能量检查 / 事实核查 — 写完必过

### 标记式改稿

永不抹除原文。用三种符号在原文上叠加标记：

- `~~删除线~~` — 建议删除或被替换的原文
- 🆕 — 新增或改写的内容
- ⚠️ — AI 撤回之前的判断，还原原文

用户能一眼看出：哪些是自己写的，哪些是 AI 建议改的，改了为什么。

## 安装

**推荐：豆包、WorkBuddy、Claude Code、Codex 与其他支持 Skills 的 Agent**

在终端执行：

```bash
npx -y skills add donlin8964/dlskill -g --all
```

安装后回到 Agent，输入 `/dls` 即可开始。

## 更新

已安装 dlskill 时，直接对当前 Agent 说：

```
更新 dlskill
```

它会同步官方 dlskill，不会修改你的本地存档和创作记录。版本变化见 [GitHub Releases](https://github.com/donlin8964/dlskill/releases)。
